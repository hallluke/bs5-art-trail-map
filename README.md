# BS5 Art Trail – Interactive Venue Map

An interactive map of art-trail venues across East Bristol, created using Python.

The map brings together venue locations and information about participating artists, including descriptions, venue types and opening times. Visitors can explore the area, select individual markers and use the layer controls to explore different venue categories.

## View the map

Open the [interactive map](https://hallluke.github.io/bs5-art-trail-map/)

## Technologies

+ Python for extracting the source data from a PDF
+ Pandas for data manipulation and cleaning
+ Nominatim for Geocoding
+ Leaflet & Folium for generating the interactive mapping
+ OpenStreetMap and CARTO for the basemap tiles

## Source code

The repository currently contains the generated HTML map. The Python script and supporting data-processing code may be added later.

## Notes

This map represents the locations for the September 2026 edition of the art trail and is retained as a project demonstration rather than a current guide to participating venues.
